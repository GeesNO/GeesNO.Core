# GeesNO.Core.Contracts

GeesNO.Core.Contracts contains the public contracts for GeesNO.Core
integrations, capabilities, manifests, operations, tools, providers, and the
neutral operation profile.

The package depends on GeesNO.Core.Primitives for shared primitive types. It is
intended for integrators defining typed operations and capability providers
without depending on Runtime internals.

This package is part of the GeesNO.Core Developer Preview. The public API is
pre-1.0 and may change before a stable release. See the repository
documentation included with the GeesNO.Core source distribution for versioning,
compatibility, security, contribution, and trademark policies.
