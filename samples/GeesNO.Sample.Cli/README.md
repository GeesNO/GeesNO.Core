# GeesNO.Sample.Cli

Status: non-normative sample application.

This console application demonstrates direct consumption of the public GeesNO.Core Runtime facade with the neutral reference simulator.

```bat
dotnet run --project samples\GeesNO.Sample.Cli -- --help
dotnet run --project samples\GeesNO.Sample.Cli -- capabilities
dotnet run --project samples\GeesNO.Sample.Cli -- echo hello
dotnet run --project samples\GeesNO.Sample.Cli -- describe
dotnet run --project samples\GeesNO.Sample.Cli -- validate hello
```

The sample is not SDK, not normative Core and not a final product CLI.
